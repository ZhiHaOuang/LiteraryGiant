# lg-execution

通过 DSH llm.prepareCall 执行一次有界文本请求，不启动工具循环、不自动重试。持久账本先预留费用上限；重复请求不重复付费；重启后未知结果保留预留额，需人工核对。默认预算为 0，须配置模型、价格和账本路径后使用。价格由作者确认配置，不能保证供应商实际计费规则不会改变。

此插件是文学短任务执行基础，尚未实现复杂工作流调度或完整旧 Runtime 迁移。已做三组各三次的精确选区修改对照；此任务没有工具调用，不能作为 OPS 文件操作能力或长篇文学质量结论。完整数据见项目 docs/dsh-plugin-validation-20261107.json。

## 可选原生会话预算

guardNative 默认 false。显式启用后通过公开 llm/stream 拦截点，在每次原生请求发送前使用同一账本预留预算，核对固定模型、文本输入大小、输出上限与 nativeMaxCallsPerSession（默认每会话累计 8 次，跨重启保留）。文学短任务预留成功后，预算检查按该次请求对象一次性核销。其他插件即使使用同一用途标签，仍按原生请求检查和预留。此开关约束当前插件作用域内的原生和辅助模型请求，不自动改变提示词、工具、模型或 DSH Agent loop。

原生账本仅保存请求哈希、会话标识、用途、字节数、工具数量、用量和耗时，不另存提示词或模型文本。未知用量不按零处理；失败／取消不释放可能已收费的预留。仅支持文本输入，图片／文件不能借文本价格估算。原生超时和取消仍由 DSH 负责；停用插件等待已开始的请求结算。使用前配置该作用域实际使用的模型与价格，其他模型会被拒绝。原生调用每次经过边界均登记，不代替 DSH 的任务幂等或重放协议。
