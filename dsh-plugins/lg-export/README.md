# lg-export

安装后在 DSH 侧栏打开「作品导出」，选择已在控制台登记的小说、导出内容与文件格式。下载复用 DSH 的 fileActions 服务。桌面还支持另存为。插件只读取一次作品事务，不调用模型。

正文默认采用当前已接受或定稿的版本。优先导出合格的整章正文，没有时按顺序导出合格的场景。勾选草稿可加入当前草稿。未采用候选、驳回及归档正文均排除。

设定集、人物和世界观使用故事事实，时间线使用事件记录。默认导出正式记录，带版本来源的事实须对应当前已采用版本。勾选草稿后会标记构想和来源待复核的事实。人物与世界观按事实分类筛选。伏笔清单包含各状态与回收记录。

已鉴权的作者接口 `POST /api/lg/export` 接受 `path`、`target`、`format` 和可选布尔值 `includeDrafts`，返回文件字节。导出是阅读副本，书稿数据库与章节文件的双向同步另行处理。单份内容上限 16 MB，超限返回错误。
