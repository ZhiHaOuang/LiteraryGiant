# 主 Agent 受限直读实验与验收

**结论：未通过质量门槛，不接入日常主 Agent。** 新增只读能力的权限、来源和版本机制已通过免费回归；真实回答出现两处明确相对退化，不能用更少请求或更低 Token 抵消。候选代码仍在 LitIsLand，本批未修改生产插件、日常配置、DSH Core，也未读写真实 Projects 和 Library。此目录只有实验交付。

交付前发现主项目在本轮期间已有其他遥测与故事时间投影更新，涉及本次追踪的 13 个文件，见 [并行变更记录](concurrent-project-changes.json)。没有覆盖这些变化。下述比较针对本轮开始时的两个冻结副本，不是当前主项目最新组合的认证；后续接入必须重新核对兼容性。

## 本次改动

当前 `lg-agent-teams` 主 Agent 只能准备来源、委派和读取成员产物，无法直接读取正文。简单原文查询也可能需要启动分析成员。隔离候选新增 `lg_team_read({source_id})`，主 Agent 可读取本会话已冻结的完整正文、段落号、作者要求及故事资料；与成员共用同一来源投影，没有摘要、检索裁剪或压缩。

执行前检查主会话、来源归属、当前作品和版本。拒绝未知来源、跨会话、跨书、陈旧正文或资料、额外扩大范围参数及成员调用；不开放任意文件或 Shell。现有作者要求明确委派时，仍须委派。代码和 Prompt 的五文件差异在 [未应用的候选补丁](candidate.patch)，不能把 `git apply --check` 通过理解为获准部署。

旧实验的 `complete:true` 提示词覆盖问题在当前三职责插件中已修复，本批没有重复修改。Ops 不在文学总指挥的获准工具范围中；此次只读审计未发现足以支持修改 Ops 源码的新缺陷，也没有执行其完整效果对照。这里的结果不能归因于 Ops、Memory 或 Superpowers。

## 固定实验与证据

- 六道原创合成任务，每题两臂、两轮，共 24 次任务、12 组对照。覆盖单引文、不同自述、多档条件兑换、人物认知、未知日期及显式单成员分析。每题前两章可读，第三章放置未授权哨兵。所有请求均未出现该哨兵或评分字段。
- DSH 0.2.2-rc.1，真实 CLI 和原生 AgentLoop／spawn。关键源码与构建产物均与项目核对，见 [宿主记录](host-equivalence.json)。两臂固定 `deepseek-account / deepseek-flash / reasoning off / maxTokens 6000`，沿用已交付三职责实验设置，不代表更高推理档位的结果。
- 第二轮反转每题版本执行顺序。题目、候选和验收要求在模型调用前冻结；没有失败重试、best-of 或付费裁判。输入及正文匹配，24 个合成作品目录的前后文件哈希一致。
- 基线 23 项、候选 32 项回归通过，候选新增 9 项覆盖完整约 42 KB 中文／emoji 输入及权限、版本限制。预算器 13 项和真实原生主从循环预算测试 3 项通过，均无跳过。两臂真实 CLI 免费预检通过。首次隔离启动缺 AJV 的失败已保留，不计成模型效果。
- 两个审读 Agent 分别隐去版本标签复核一轮，主执行者再核对原文、输出与轨迹。这是模型辅助复核，**不是独立人类盲评或官方基准成绩**。对解释有争议的项目保留待裁定，不与确定错误混算。

完整材料：[题目与评分条件](cases.json)、[24 份最终回答](answers.json)、[逐题用量](paired-metrics.json)、[第一轮审读](reviews/round1-review.json)、[第二轮审读](reviews/round2-review.json)。审读标签对应 [第一轮映射](reviews/round1-mapping.json) 和 [第二轮映射](reviews/round2-mapping.json)。

## 逐题结果

下表保留实际问题，不以平均分替代逐题验收。主要答案正确也不能抵消后面的错误说明。

| 题目 | 第一轮 | 第二轮 |
| --- | --- | --- |
| 01 单引文查证 | 两臂都在说明中再引用第二处原文，违反数量要求 | 候选遵守一处；基线仍多引一处 |
| 02 两次自述 | 基线错报段落总数；候选将成长／居住地写成出生地 | 两臂主要要求通过 |
| 03 条件兑换 | 基线只交付等待通知；候选表格正确但后续解释自相矛盾 | **明确退化**：基线保留一碗剩 6 票的有效方案；候选划去该方案，错误声称 6 票买不了 6 票的粥 |
| 04 事实与认知 | 候选主要要求通过；基线出现与实际只读行为不符的“改动仅限”说法 | 候选主要要求通过；基线对已建立状态的过度不确定性保留待裁定 |
| 05 未知日期 | 两臂均有额外不当解释；候选将缺日期误说成与恰好一年矛盾 | **明确退化**：候选追加“至少约一年”的错误下界；2025 年末到 2026 年 6 月可以不足一年 |
| 06 明确委派 | 两臂都只派一名 analysis；基线有额外无依据断言，候选主要要求完成 | 基线再次只交付等待通知；候选完成汇总，但额外因果猜测保留待审 |

两次基线等待通知并非实验程序过早退出：成员已经完成，主 Agent 的后续请求已经包含 `subagent-settled / completed` 通知，模型仍声称正在处理。它没有调用完整结果工具。正常退出和 `turnEnd: completed` 只能证明轮次结束，不能证明作者任务完成。

## 下一步的具体目标

保留本次只读入口作为待验证能力，不将其自动推广为所有任务的直接回答策略。优先区分原文定位与需要条件组合、计算、时间推断的分析任务；同时检查主 Agent 收到成员完成通知后是否取得并交付实际结果。完成状态与结果引用应由执行层提供可核验信息，模型的“仍在处理”不能覆盖真实状态。

下一轮先解决必要结果遗漏、额外事实失真和完成判断，再比较效率。可以研究当前 `reasoning off` 设置与任务策略的关系，但本批没有做该消融，也不能保证提高推理档位就解决问题。任何新方案仍需旧失败案例回归和未用于调参的新题；不得用本批已知题的修补结果冒充泛化能力。

本批不覆盖长篇连续创作、文学文笔、真实作者采用价值、日常所有插件共存或跨平台故障恢复。机械回归通过与文学效果通过分别记录。
