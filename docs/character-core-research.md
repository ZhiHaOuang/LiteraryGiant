# 人物描写与人物档案怎样衔接

2026-11-22 · LiteraryGiant 人物 core 研究提案。本稿对照正在使用的 `lg.outline.character.v1`。文中的栏目、字段和试验属于下一版设计选项。

**优先改两处。** 第一，让协议能说清一个词是字段名、可选值、搜索标签，还是写作者可以照着组织一句话的示例。第二，让作者在写场景时拿得到有出处的举止、对白和感知细节。前者解决“结构看起来很整齐，但同一条资料不知道该填在哪里”，后者解决“人物资料都填了，写出来的人还是一个样”。

## 研究给出的几种答案

这些来源分别研究写作、文本理解、资料抽取和读者评价。下表最后一列是对 LG 的设计判断。这是围绕产品问题选取的一组一手材料，未做穷尽式文献检索。

| 材料 | 原研究或作者实际处理的问题 | 对人物档案的启发及边界 |
|---|---|---|
| Jannidis，《Character》；Niederhoff，《Focalization》 | 文本可以明说人物的属性，也可以让读者从行为推知。叙述可以限制信息，使其符合某个观察者的经验与知识。 | 保存“谁在怎样的情境下作出的判断”。一句上司眼里的“怯懦”，可以成为有价值的关系材料；作者需要额外依据才能把它提升为人物的一贯性格。[人物塑造](https://www-archiv.fdm.uni-hamburg.de/lhn/node/41.html) · [叙事聚焦](https://www-archiv.fdm.uni-hamburg.de/lhn/node/18.html) |
| 小说家 Josip Novakovich 的 Open University 写作教材 | 作家可以用概述、外貌、习惯及具体场景塑造同一个人；场景能让读者同时听到人物的用词、看到动作并自行判断。 | 把“读者通过什么认识了他”作为检索入口。搜一个沉默寡言的人，应能取回一段有辨识度的回应或沉默，以及当时对面是谁。这是写作方法，不能据此把每个人都补全成四张表。[Portraying a character](https://www.open.edu/openlearn/mod/oucontent/view.php?id=20441&section=1.3.1) |
| Rashkin 等，Story Commonsense，2018 | 在短故事中分别标注促使人物行动的动机，以及事件之后的情绪反应。部分心理内容由标注者推断。 | 对同一行为分别问“为什么做”“做完以后怎样”。一次害怕可留在场景；跨情境反复出现的触发与应对方式才支持性格侧写。这项研究使用简单短故事，无法直接提供网文长篇的完整人格分类。[原研究与标注](https://uwnlp.github.io/storycommonsense/) |
| 中文小说引语研究，2024 | 作者同时标注说话人、受话人、言说方式和文本提示。只认出说话人还原不了完整互动。 | 写对白时建立“对谁说、在什么场合、用什么称呼或句式、想产生什么效果”的小样本。前三项可直接取证，意图可暂缺。区分人物自己的语气、复述他人和当场伪装。[Identifying Speakers and Addressees](https://arxiv.org/abs/2408.09452) |
| CHIRON，Findings of EMNLP 2024 | 对原文分题提取对白、外貌与个性、知识及情节相关信息，再验证陈述是否受片段支持。研究从英语协作故事中筛出 529 篇，其中一项下游任务是遮蔽姓名后识别人物。 | 分题提取、逐条核验很适合我们的独立审查。可以用隐去名字后能否认出说话人测试辨识度。人物识别的成绩尚不能证明续写正文更好，也不足以把它的四类照搬为网文数据库目录。[论文与任务](https://aclanthology.org/2024.findings-emnlp.499/) · [原文表 1](https://aclanthology.org/2024.findings-emnlp.499.pdf) |
| TimeChara，2024；Sancheti 与 Rudinger，2025 | 前者测试模型扮演故事中某一时点的人物是否会使用时点以外的信息；后者研究全书中人物关系的逐步演变，并说明其关系追踪缺少逐处的金标准注。 | 人物写作视图需要同时提供“哪一幕之前”和“谁有机会知道”。同一时点也能同时存在公开盟约和私下敌意，必须再记关系维度、观察者或持有人。模型之间意见一致仍需原文复核。[TimeChara](https://aclanthology.org/2024.findings-acl.197/) · [关系演变研究](https://aclanthology.org/2025.wnu-1.12/) |
| STORIUM，EMNLP 2020；CharacterMeet，2024 | STORIUM 收集带作者自写目标和属性标注的协作故事，允许作者编辑机器建议的续文；CharacterMeet 观察 14 位创作者借助情境化对话逐步构建人物。 | 作者构思期可以先试写出几种相互竞争的动机；抽取已写正文时则要标明出处。保留“规划、试写、已写事实”的界线。可记录作者要改动多少才肯采用，作为生成是否有用的证据。[STORIUM](https://aclanthology.org/2020.emnlp-main.525/) · [CharacterMeet](https://researchportal.hkust.edu.hk/en/publications/charactermeet-supporting-creative-writers-entire-story-character--2/) |
| 中国网文作者访谈与访谈研究 | 爱潜水的乌贼谈及如何从社会生活素材中为次要人物写出可信的生活。聂茂、张旭梳理了 43 位网文作者的访谈，讨论主配角在事件参与和叙事篇幅上的差序。 | 少量出场也值得保留人物自己的生计、关切或选择。一名只见两次的门房，可以靠“他会为了什么冒险放行”立起来。按人物在作品里的职责控制资料深度，群像可以有数条并行重心。[作者访谈](https://www.chinawriter.com.cn/n1/2022/1207/c404024-32582252.html) · [访谈研究](https://image.chinawriter.com.cn/n1/2023/1018/c404027-40097827.html) |
| ChangJuan，Findings of ACL 2026 | 研究以 300 部中文小说、评分和读者评论研究整书评价，按人物、情节等方面归纳意见，并探讨类型差异。 | 用代表段落和整书前后文共同验收。悬疑读者可能看重信息差，群像读者可能更看重多个角色能否各自推动局势。读者共识可以评价阅读效果，不能作为人物事实来源。[ChangJuan](https://aclanthology.org/2026.findings-acl.2044/) |

## 人物描写有哪些可观察的方面

一个例子能同时服务两个问题。某人每逢被盘问就把钥匙攥进掌心，这段文字可以按**动作或习惯**找回；它是否支持**害怕失去控制**，取决于其他语境。一处原文保留一个证据入口，各种解读附各自的依据。建议将下列项目作为来源检索维度，允许多选。

| 描写渠道 | 值得保存什么 | 容易误判什么 |
|---|---|---|
| 外貌、形体与感官印记 | 身形、面容、声音质地、步态、会影响辨识的装束或物件；标出观察者和阶段 | 一次穿着变成永久外貌；旁人觉得他可怕被写成客观长相 |
| 对白与声音 | 称呼、词汇、句长与停顿、转移话题、沉默；关联受话人及一小段原话 | 把当场辞令写成常用口头禅；把叙述者措辞算到人物头上 |
| 动作、反应与习惯 | 当场具体动作；有条件、有后果的重复行为；刻意改变习惯的例外 | 一次退让就记成懦弱；手势反复出现就当成心理诊断 |
| 内在活动与注意 | 明写的念头、记忆、自我解释、注意到或避开的细节；是谁的视角 | 从外部视角擅自填入真实动机；看到某物就等于理解其意义 |
| 选择、回避与代价 | 面对哪两个选项，采取或拒绝了什么，愿意承担什么；当时有哪些外部限制 | 把迫于权力或缺乏资源的行为误判为价值偏好 |
| 他人的反应、评价与称呼 | 谁这样称呼或评价他，旁人怎样改变自己的行为，与其本人说法有何差异 | 全镇传言被写成人物的真实履历 |
| 环境、物件与社会生活 | 人物如何使用空间、谋生、维持关系，物件何时具有识别或记忆意义 | 所有随身物品都进 Main；把场景布置归为人物特质 |
| 叙述者概述、对照与留白 | 谁作概述；两个人物在相似处境下如何作出不同选择；什么仍被有意隐去 | 把文学效果、主题解读或未来反转提前写成人物可用知识 |

## 审计现有八组

当前人物目录有 8 个模块、40 个二级类别。条目已经要求稳定键、类别、描述、标签、适用范围、信息性质和来源；有向关系、认知立场、目标进展、情节链接也已有部分强校验。设计稿已经区分固定枚举、开放词表和原值。实际目录的 `vocabulary` 却是一段显示文字，面板按顿号和分号拆成相同的标签。这使“句式”“反问”“进行中”“先前状态 → 新状态”看起来可以按同一方式填写。另一个限制是，Story Data 的 Main 读取接口服务于作者当前视图；Books 已有时间与人物查询，两条读取路径的可见范围需要分别验证。[现行词表](character-core-taxonomy.md) · [目录](../dsh-plugins/lg-storydata/src/character-core.json) · [面板转换](../dsh-plugins/lg-storydata/src/character-protocol-panel.jsx) · [条目结构](../dsh-plugins/lg-storydata/src/contract.json) · [校验规则](../dsh-plugins/lg-storydata/src/character-core.js) · [读取边界](../dsh-plugins/lg-storydata/README.md) · [Books 查询](../dsh-plugins/lg-books/src/story-data/queries.js)

| 现行组 | 还缺什么区分 | 建议的处置 |
|---|---|---|
| 身份与辨识（6） | 名称类型、描述字段、主角职责的使用者不同。写出身已有入口，较难检索出身怎样塑造后来的选择。 | 名称、社会身份与生计保留；把塑造人物的旧事指向经历。主角、视角、对照角色归作者侧。 |
| 目标与动机（4） | 一个目标可以包含驱动力、阻碍、代价和阶段进展。今天能分别建条，却欠缺清楚的目标归属。 | 一条目标贯穿各字段，允许同一人物同时追求两个冲突的目标。外界期待、自称愿望、已采取行动可有不同依据。 |
| 性格与表达（5） | 情绪反应、价值取向、说话习惯、伪装策略的时间尺度不同。现有表达类已有语域和句式，具体写作样本藏在原文里。 | 保留有条件的选择倾向；把声音、姿态、自我呈现做成独立阅读入口。给反例留位置，有意反常也提供写作材料。 |
| 能力与限制（5） | 某项能力的等级、使用条件、代价和暂时不可用容易分散。 | 按具体能力聚合。一次成功使用只证明该次成功。书级扩展可加境界、功法，通用核心保存表现与约束。 |
| 当前处境与资源（5） | 常驻特征、局部变化、支配权混在一层。拥有、可以调用、现在带在身上是不同状态。 | 保留有时效的处境；链接能力、物件、地点。永久特征共享同一事实引用；当时的伤势与阶段性失能可独立变化。 |
| 认知与秘密（5） | 命题、获知途径、立场、修正是同一认知的组成部分；信息究竟已向读者揭示到哪里取决于正文顺序。 | 按“持有人＋命题”聚合，挂接来源、立场及时间。世界真相、甲的误信、乙的怀疑、读者的揭示点分别检索。 |
| 关系与承诺（6） | 同一对人有制度关系、利益关系、私人态度，且常不同步。承诺还可能贯穿多个情节。 | 保留方向、维度、事项和可见范围；把承诺内容和履约进度交给 Plots。人物侧只记现在影响选择的约束与链接。 |
| 关键经历与变化（4） | 事件角色、先后和因果是联系；它们一旦被写成逐章独立摘要，最易和 Plots、状态史重复。 | 以事件和变更引用组装人物历程，显示哪些决定、得失或反复经历仍在起作用。人物经历也允许维持原信念或留下未兑现的先例。 |

## 建议作者面前看到的七个问题

这是写作时的阅读布局，已有模块 ID 和审查链可以继续承担存储。每栏以有来源的短句为主，标签只帮助检索。作者规划中的内容另标“规划”；未写入正文的安排不会流入受限人物视角。

| 建议栏目 | 二级内容 | 一条有用记录应能回答 |
|---|---|---|
| **身份与生活来历** | 名称与称谓、所属与职责、家庭与成长、职业与日常、阶段身份 | 谁用这个名字称呼他？哪段成长或生计经验今天仍影响他？ |
| **外在呈现与人物声音** | 体貌与感官印记、动作习惯、对白与称呼、内在语气与注意习惯、公开面具 | 隐去名字，还能通过哪一个细节、判断或说话方式认出他？对不同的人又有什么变化？ |
| **欲求与冲突** | 具体目标、驱动力、阻碍、所押上的东西、不可兼得的目标、进展 | 他此刻想让谁或什么发生改变？失败具体会失去什么？ |
| **价值、性情与选择** | 价值优先序、习惯策略、触发与应对、自我理解与矛盾、反例 | 当守诺和自保不能两全时，他在什么条件下选过哪一个？他怎样解释自己的选择？ |
| **认知与信息差** | 持有的命题、获知与误信、怀疑、秘密和对他人的预期 | 站在这一章这一个人的位置，哪些话能说、哪些细节能看懂、哪些仍是误解？ |
| **关系与社会位置** | 血缘和职责、权力与依赖、亲疏与信任、公开与私下、仍有效的义务 | 谁能要求他做什么？他信任对方的哪一面？同一关系的另一方怎么看？ |
| **能力与当前行动条件** | 技能与边界、代价、身体与心理状态、所在地与可用资源、外部压力 | 他平时会不会做？这一幕现在能不能做？使用能力将付出什么？分别标明长期条件与临时状态。 |

另有两个跨栏视图。**人物历程**从情节、选择及条目历史生成，读者能看见哪些压力改变了谁，或者谁顶住压力依然如故。**作者的叙事安排**保存阶段主配角、视角承担、镜像或对照、预期弧线和读者揭示位置。群像可以安排多个重心；推理小说也可以让明知真相的人暂不承担视角。这些视图引用同一批资料，实际写作可以按场景只读其中一小部分。

**三种粒度就够开始试用。** 主角和长期对手可积累有条件的行为模式与表达样本。常驻配角优先留一个自己的诉求、一条关键关系和能辨认的细节。临时出场者可以只留下称呼、场景职能和必要的辨识依据。某人若在后文成为主角，可凭新的依据逐步扩展。仙侠境界、悬疑不在场证明、言情关系阶段走书级扩展；职业、性别、长相等静态信息不能推导价值观或行为倾向。

## 用罗兰暂缓审判做交叉检验

以下沿用项目已记录的第一章段落位置与解读。每行示范档案的去向，均未提交成新的作品事实。[广场审判的既有段落对照](character-core-taxonomy.md#用广场审判校准分类)

| 当时可见的材料 | 档案如何使用 | 下一场能据此写什么 |
|---|---|---|
| 第 24 段，程岩对仅凭众人归罪便执行绞刑持异议 | 一次具体判断，关联当场阻止处刑的目标。跨场景的一贯价值排序仍待证。 | 在相似压力下，可以调用这一先例；若要写他普遍反对某种制度，还得找别的依据。 |
| 第 25–26 段，他有意模仿原主的任性来改变裁决 | 行为证据有两个索引——公共场合怎样表现，以及这次表现服务什么意图。Main 候选保留一条带情境的策略和来源。 | 写廷臣视角可以呈现姿态及命令；写罗兰视角才可调用此处明示的伪装意图。 |
| 第 25、27–29 段，案件延后，卡特提出异议后仍随行 | Plots 更新案件进展，人物历程回链本次决定。关系里可找到上下级这一背景，异议本身不足以改写卡特的私人立场。 | 后文能继续处理待裁决的案件；人物对白仍有上下级约束。 |
| 第 41 段，罗兰明确继续扮演四王子的打算 | 在这个正文截止点才建立较持续的伪装目标，与先前行为相连。 | 回写广场一幕时屏蔽章末才明确的信息，续写下一章时可取回该阶段目标。 |

同一场中，扔手令、伸懒腰等细节保留在原文。写类似公开场合可取一个动作作参照，避免以后每次下令都复制同一动作。外貌、武力、私人关系在这次没有新依据，审查给出“无更新”即为有效结果。

## 建议先验证的协议变化

1. **给目录项定型。** 先试“语言与互动风格”和“目标进展”。例如“受话人”是对象字段，“反问”是开放的表达策略，“受阻”是目标的受控状态，一句真实对白是带段落引用的样本。读接口可先附上种类和稳定 ID，旧词表继续可读。先验证 UI 和分析 Agent 能否作相同解释。
2. **给同一判断留证据层次。** 记录说明谁在何时说、做、看见或推断了什么。审查时区分“叙述明示一次策略”“已观察到多次条件性模式”“作者计划未来这样发展”。保留反例、观察者和有效范围。不预设出现两次便足以证明性格。
3. **在相同写作条件下比较收益。** 用罗兰作已知回归，再选未参与设计的对话、误认身份和配角独立做决定的场景。两套材料使用相同模型、截止段落、作者要求和上下文预算。先让两位标注者独立归类，记录重复入档及争议原因，再由作者盲评续文里的声音辨识、动机可信、事实与知情越界、采用所需修改。保留两稿都不满意的结果。若只改善识别而作者仍需大改，对该机制的评价就限于检索。
