# 网文人物 core 分类与标签词表（v1）

这份词表用于回答三个问题：资料属于哪个人物模块，怎样让不同人物用同一种格式记录，以及哪些变化值得下次写作时主动读入。八个一级分类沿用前次讨论。八类、四十个二级类别及其稳定 ID 已进入 lg-storydata。二级类别固定，文学标签开放。机器可读目录见 [人物 core](../dsh-plugins/lg-storydata/src/character-core.json)，提交与读取约定见 [插件协议](../dsh-plugins/lg-storydata/README.md)。

## 怎样使用词表

**类别**决定一条信息的结构，例如“对他人的态度”。**标签值**供比较和检索，例如“信任”。**条目**说清完整含义，例如“甲信任乙的医术，但不肯把身世告诉乙”。同一个人物卡上的“医师”“信任”“重伤”分别属于职业、对特定对象的态度、身体状态，应通过各自字段检索。

建议区分三种值域。能决定程序行为的值采用**固定枚举**，如目标状态、依据性质。需要跨人物比较的文学词采用**可扩词表**，如动机、关系种类、表达策略，给标准词登记近义词。专名、命题和条件采用**原值或引用**，如姓名、具体目标、组织 ID、能力代价。下表的斜线表示可选示例；除明确标为固定的值外，无需穷尽。

## 一、身份与辨识

| 二级类别 | 字段或起步词表 | 统一记录方式 |
|---|---|---|
| 名称与称谓 | 本名、别名、化名、绰号、封号、敬称、贬称 | 一个显示名；其余逐条记录“名称＋称谓类型＋谁这样称呼／使用场合”。多人使用同一称号时仍各有自己的 ID。 |
| 基本辨识 | 年龄或年龄段、性别／性别表达、族属／物种、出身地 | 按作品需要选填。区分实际年龄与外观年龄；无叙事依据不推算精确数值。 |
| 身份背景 | 家世、成长环境、职业／职务、社会地位、组织归属、阵营归属 | 职业、组织和阵营可同时存在。保存实际值及生效时段，例如“职务＝领主”“所属＝某王国”。 |
| 身份层次 | 真实身份、公开身份、掩护身份、被误认身份、旧身份 | 每项指向具体身份及知情范围。“被谁误认成谁”另引用相应人物认知。 |
| 外貌与辨识特征 | 体貌轮廓、发／眼特征、显著标记、体态步态、惯常装束、声音质地 | 特征用短语，例如“左眉断痕”；可另带一段简短外貌描述。临时换装记处境，伪装另注明适用范围。 |
| 叙事定位 | 重要程度、叙事身份、视角承担 | 重要程度沿用既有 core／major／supporting／minor／unknown；主角、对手、导师、盟友等角色定位及视角另记，标明全书或阶段。故事主角也可以不是当前视角人物。 |

## 二、目标与动机

| 二级类别 | 字段或起步词表 | 统一记录方式 |
|---|---|---|
| 目标内容与跨度 | 当场意图、阶段目标、长期追求 | 目标用“动词＋对象／结果”短句，跨度单选。不同目标可并存，只有存在明确取舍时才排优先级。 |
| 驱动力 | 求生、自保、保护、归属、认可、责任、求知、自主、求强、利益、复仇、赎罪、信念 | 保存“为什么偏要做这件事”。近似动机可并存，给出对该人物成立的具体理由。 |
| 阻碍与取舍 | 自身限制、他人阻挠、制度限制、资源短缺、信息不足、目标冲突；代价、底线 | 写清“哪两个东西不能兼得”“他愿意放弃哪一个”。一次选择最多证明这一情境下的取舍。 |
| 目标进展 | 建议固定为进行中、受阻、搁置、达成、放弃 | 状态随情节更新。目标改向时把旧目标与新目标关联；已经完成的当场意图退出“当前追求”。 |

动机解释当下选择；价值取向解释跨场景反复出现的选择。二者都有依据时可以关联，避免把同一句话分别存两份。

## 三、性格与表达

| 二级类别 | 字段或起步词表 | 统一记录方式 |
|---|---|---|
| 价值与取舍倾向 | 守诺、重情、重秩序、重自由、重公平、重实效、重名誉、重自保 | 最有用的值是冲突时的选择，如“守诺与晋升冲突时，曾选择守诺”。区分自我宣称、别人评价和已经做出的选择。 |
| 决策与处事倾向 | 审慎、果断、冲动、好疑、冒险、回避冲突、迎面交锋、先观察再行动 | 给词加情境。审慎和果断可以分别成立于筹备阶段与临场执行。 |
| 情绪机制与脆弱点 | 触发因素、外显反应、自我调节、恐惧、软肋、防御方式 | 记录“遇到什么 → 怎样反应”。瞬间紧张留在原场景；持续妨碍行动时另记当前状态。 |
| 语言与互动风格 | 直陈、反问、讽刺、自嘲、安抚、试探、转移话题、命令、沉默；语域、句式、称呼习惯 | 分对象和场合。口头禅保留少量原话，普通台词只作证据。声音沙哑属于辨识，习惯压低声线来施压属于表达。 |
| 公众面具与内外差异 | 刻意伪装、角色表演、言行反差、价值冲突、自我欺骗 | 记录“表面呈现／实际意图／面向谁”。有直接叙述可记一次明确策略；单次策略不自动成为稳定性格。 |

“腹黑”“圣母”“疯批”等读者印象可以作为带归属的评价。抽取成写作材料时应展开成可以辨认的行为、触发条件或价值冲突。

## 四、能力与限制

| 二级类别 | 字段或起步词表 | 统一记录方式 |
|---|---|---|
| 能力领域 | 体能、战斗、技艺、专业知识、调查推理、交涉、组织指挥、超凡能力 | 领域作检索，能力名称作条目，如“医疗 → 战场止血”。职务赋予签令权，并不能证明善于指挥。 |
| 掌握程度 | 初学、可独立使用、熟练、精通；未明 | 保留作品自己的等级体系；仅目睹一次成功时记录“在某条件下成功使用过”，不据此定级。 |
| 条件与边界 | 前置知识、工具／材料、身体条件、环境条件、对象限制、距离／持续时间 | 用原文允许的粒度描述；原文给出数值才记录数值和单位。 |
| 代价与失效 | 消耗、反噬、冷却、受克制、失控、能力暂失 | 能力条目记通常规则，当前是否可用记状态；关联同一能力。 |
| 学习与变化 | 学会、突破、掌握新用法、退化、失去、恢复 | 真正改变后续可采取行动的变化进入 Main，训练的重复动作留作事件依据。 |

## 五、当前处境与资源

| 二级类别 | 字段或起步词表 | 统一记录方式 |
|---|---|---|
| 生存、身体与持续心理状态 | 生存状态、伤病、中毒、疲惫、恢复中、持续恐惧／哀伤 | 按属性分别维护最新值。公开失踪或被认为已死，不足以将客观生存状态写成死亡。 |
| 位置与行动自由 | 所在地、在途、受困、被拘禁、受监视、获释、可自由行动 | 地点引用环境；行动自由单独记录。位置未知不代表自由或受困。 |
| 处境与外部压力 | 受追捕、身份暴露风险、期限将至、受保护、被孤立、受制于人 | 记仍在起作用的压力及解除条件；短促的现场气氛回到场景。 |
| 物资与支配权 | 资金、物品／装备、据点、人员、职权、渠道、时间窗口 | 区分“拥有、借用、可调动、实际控制、暂不可用”。优先记会改变行动选择或维持连续性的资源。 |
| 身体外观的阶段变化 | 伤痕、残疾、易容、标记、装束变化 | 短时形态写状态。成为持续辨识点后，由身份模块引用该特征。 |

## 六、认知与秘密

| 二级类别 | 字段或起步词表 | 统一记录方式 |
|---|---|---|
| 认知主题与命题 | 身份、事实、规则、因果、动机、计划、危险 | 用稳定主题与一句完整命题，例如“父亲生死 → 父亲已死”。明确认知持有人。 |
| 持有态度 | 相信、怀疑、否认、未确定 | 沿用既有 knowledge.stance。将“知道”作为较强的叙述措辞时，核对证据；认知确定程度与命题客观真伪分开。 |
| 知情来源 | 亲历、目击、被告知、听闻、推断、记忆、误导 | 记录获知途径与时间，必要时指向告知者。被告知只证明接触了消息，不自动等于相信。 |
| 信息差与秘密 | 隐藏身份、隐瞒意图、保密事实、错误归因、单方知情、部分揭露 | 记录谁知道哪部分、谁被明确蒙在鼓里、何时揭露；没有证据时保留未知。读者已经知道的内容另由揭示记录承接。 |
| 认知变化 | 首次获知、产生怀疑、修正判断、被证实、被推翻、遗忘 | 只连接同一主题的前后条目。人物相信“父亲已死”与世界事实“父亲健在”可以同时存在。 |

## 七、关系与承诺

同一对人物可以同时有血缘、职务、合作和单向敌意。每个标签绑定**主体、对象、维度**，必要时附公开范围和生效时间。

| 二级类别 | 字段或起步词表 | 统一记录方式 |
|---|---|---|
| 血缘、家庭与亲密身份 | 父母／子女、手足、配偶、伴侣、养育／被养育、监护／被监护、家族成员 | 对称关系标明对称，非对称关系保留方向与反向显示词。“父亲”须能回答是谁的父亲。 |
| 社会与职责关系 | 师父／弟子、上级／下属、领主／臣属、雇主／受雇者、同僚、同门、同学 | 保存制度或组织依据。履行职责通常不会自动改变亲密或信任。 |
| 合作与利益关系 | 伙伴、盟友、交易方、竞争者、对手、敌对方、庇护／受庇护、依附 | 标明合作事项与适用范围；临时共同应敌不等于永久结盟。 |
| 单向情感与态度 | 信任、怀疑、敬重、亲近、爱慕、依赖、畏惧、敌视、怨恨、嫉妒 | 写明“谁对谁、在哪方面”。允许甲信任乙的医术，同时怀疑乙的忠诚。乙的态度独立记录。 |
| 关系的公开层与阶段变化 | 公开关系、私下约定、伪装关系；建立、缓和、恶化、决裂、修复 | 只有正文支持时才记录变化。公开结盟＋私下敌视，分别存于合作维度和单向态度维度，可在同一时间成立。 |
| 承诺、债务与未决义务 | 许诺、欠债、欠人情、契约、誓约、保密义务 | 内容、履约条件和进度集中在 Plots。人物侧保存当事人角色、情节引用及对当前行动的约束。 |

## 八、关键经历与变化

| 二级类别 | 字段或起步词表 | 统一记录方式 |
|---|---|---|
| 经历对人物的作用 | 身份改变、目标转向、认知反转、能力变化、关系转折、资源得失、价值动摇／确立 | 作用可多选。事件类型“战斗／婚礼／审判”属于 Plots；在人物侧写明这件事具体改变了谁的什么。 |
| 在事件中的角色 | 决策者、行动者、承受者、见证者、受间接影响者 | 同一情节对不同人物的意义不同。出场本身不产生关键经历。 |
| 变化与延续 | 先前状态 → 新状态；出现先例、延续已有模式、形成转折 | 没有证据证明前后发生变化时，可记“有意义的先例”，不写“从此改变”。当先例被后来的转折用到时，再建立联系。 |
| 经历之间的关系 | 先于／后于、触发、促成、阻碍、修正先前判断 | 复用事件 ID。时序边和因果边分别记录，正文先出现不代表故事先发生。Main 可列少量仍影响当下的里程碑。 |

## 跨模块的共同字段

| 共同维度 | 建议 |
|---|---|
| 对象与归属 | 档案 ID、模块、必要的对象 ID；关系记录方向，认知记录持有人，称谓记录使用者。名字用于显示。 |
| 时间与作用范围 | 分开记录正文锚点、故事内有效时间、适用情境。允许“此场景”“某事件之后”“未知”。入库时间只供审计。 |
| 信息性质 | 世界所发生的事、人物判断、公开说法、他人评价、作者规划各有归属。可用原文确证“某人撒了一个谎”，谎话内容仍属公开说法。 |
| 依据与审查 | 条目绑定来源版本、段落和引文。区分原文明示、基于原文的推断、作者另行给定。审查状态与作者认可分别保存。Dashboard 默认可折叠依据。 |
| 当前性与更新 | 区分新增、补证、替换当前值、纠正旧解释、暂存冲突、无变化。建议比较同人物＋同维度＋同对象或主题＋相同有效范围。本版按模块比较整组条目，保存独立审查与不可变修订。暂存冲突可在提议中记录，待证据足够再提交。 |

**缺失值约定。** 未提及的可选项留空；“未知”用于这个问题已经提出而答案尚不清楚；“无”需要正文支持；“不适用”给未启用或确实不适合该人物的维度。这样既能保持结构整齐，也能避免每个配角得到一整页“未知”。

## 核心、按书扩展与 Main 准入

- **首批宜固定**：身份和称谓、目标及状态、条件性行为倾向、能力与限制、当前处境、认知命题与态度、有向关系、经历及事件引用。先固定结构和少量判断值；不同人物使用相同结构，允许零条更新。
- **按书另开**：修仙的境界／功法／瓶颈／渡劫，游戏的职业树／技能栏／装备槽，言情的关系阶段／共同约定，悬疑的嫌疑身份／不在场证明，权谋的官阶／继承顺位。这些包引用已有的人物、关系、能力和情节；例如言情的“公开交往阶段”不能替代两个人各自的感情立场。
- **默认放在来源或事件中**：单次动作与台词、泛化形容词、普通衣食细节、重复履职、对后文尚无持续影响的情绪。衣食细节若后来成为过敏风险、习惯、伪装或线索，可凭新证据提议进入相应模块。
- **进入 Main 的理由**：这条信息能帮助辨认人物、理解其选择、限制其可做或可知的事，或维持后文连续性。若只增加了同一判断的一条例证，保留来源；若旧判断因此改变，才提交对 Main 的修改。低戏份人物只需名称和足以区分其作用的少量条目。

## 用广场审判校准分类

| 材料 | 推荐去向 | 最小记录 |
|---|---|---|
| 程岩认为不能因众人归罪就把眼前的女子绞死（第 24 段） | 目标与动机 | 一次有明确对象的判断。该场意图是叫停当场处刑，完成后退出活跃目标。 |
| 他参照原主以往行事风格，故意摆出任性姿态（第 25–26 段） | 性格与表达 → 面具／表达策略 | 人物 Main 候选可写“在熟悉原主的廷臣面前，罗兰曾借原主的任性掩饰自己改变裁决的理由”。这是明示的当场策略。 |
| 改天再判，卡特提出异议，之后仍随行（第 25、27–29 段） | Plots → 案件状态／参与者；人物经历保留事件入口 | 案件处于待裁决；保留既有上下级关系。没有足够依据新增“释放女巫”“卡特叛离”等结论。 |
| 扔下手令、伸懒腰、具体对白 | 逐段来源 | 用于核对动作、语气与伪装方式。可从摘要跳转，不逐字占用人物 Main。 |
| 章末明确打算继续扮好四王子以免露馅（第 41 段） | 目标与动机 → 阶段目标 | 在章末建立持续目标，回链广场上的先例。两个时间点有不同的信息强度。 |

本例中，人物 Main 保留一条带情境的决策／表达理解和一个事件引用就有价值。身份、能力、关系等其他类别的比较结果可以都是“无变化”。
