日期：2026-10-22。作者指定使用智谱现有模型，先要预算建议；型号尚待账号实际可用性确认。**本文件是待批准的实验方案，本轮付费调用为零，尚无文学质量或长期一致性结论。**

## 型号与配置

官方当前列有 `glm-5.3`，可作为首选待测型号；不能将公开目录当作账号权限，也不能将旗舰定位当作文学质量证据。若作者的现有账号只开放另一型号，先明确记录并重新核价，两组必须使用同一型号，不静默回退。

当前 Mac 的 LG 公共配置位置中没有模型标识，也没有检测到 LG 可识别的智谱凭据环境变量。检查仅涉及配置存在性、非敏感模型字段和环境变量是否存在；没有读取密钥库或其他应用的私有认证。需要作者在终端或“LG：模型管理”中配置 API profile，密钥不发到聊天中。

从父仓库根目录，使用已有 LitIsLand Python，可执行以下命令。它会显示所选端点，并在终端内以隐藏输入方式接收密钥；命令本身没有密钥。若已有同名 profile，先查看名字，不使用 `--replace` 覆盖。

```sh
PYTHONPATH=LiteraryAgent/lg-cli python -m lg_cli auth add zhipu-eval --provider responses-compatible --model glm-5.3 --base-url https://open.bigmodel.cn/api/v1
```

智谱 Responses 的官方基址是 `https://open.bigmodel.cn/api/v1`；该配置独立于已有 `glm` Anthropic preset。添加 profile 会将它设为当前配置空间的活动 profile，执行前应确认该切换符合当前用途；不改正式作品的 Runtime 配置。模型管理也可选择相同字段。[官方兼容协议](https://docs.bigmodel.cn/cn/guide/develop/responses/introduction)

本轮没有执行这条写凭据命令。配好后先用合成输入验证实际型号、流式终止、结构输出、usage 与输出上限；文档声明兼容不等于 LG 已在真实端点验收。账号使用的是 Coding Plan 或其他专属端点时，先核实对应端点与计费资格，不把它等同于本方案的按量 API。

## 建议预算：首轮人民币 5 元

8 次正文／润色生成：4 个独立合成样本、每样本两组各一次；最多另加 2 次短协议探测。所有请求都计入同一个建议预算，失败但可能计费的请求也计入；不自动重试、不调用搜索或其他收费工具、不并发发出剩余请求。

按官方今日按量价格、不计缓存折扣，`glm-5.3` 每百万输入／输出 token 为人民币 8／28 元。若每次生成的**完整输入**不超过 12,000 token、总输出（包含供应商计费的推理开销）上限为 2,048 token，8 次估算为：

`8 × (12,000 × 8 + 2,048 × 28) / 1,000,000 = 1.226752 元`

两次探测若各不超过 512 输入和 2,048 总输出 token，再预留约 0.123 元，合计约 1.35 元。建议 5 元留出材料计数与实际协议的余量；它是建议费用上限，**不是现有宿主已经实现的全局金额门禁，也尚未获得费用执行批准**。[官方 API 定价](https://docs.bigmodel.cn/cn/guide/start/pricing)

执行前须按真实端点计数核对完整系统指令、材料、Schema、所有回填与输出参数；字符上限不是 token 预算。若不能确认推理 token 如何计入输出上限、服务忽略参数、用量缺失或存在额外费用，停止预实验，不使用上式承诺硬账单上界。每次请求前按剩余额度预留，结束后记录 usage 与费用；响应丢失、超时或不完整时保留“费用可能已发生”，不重发。仅截断本地显示不能阻止供应商继续计费。

备选 `glm-4.7` 在输入不足 32K 且输出至少 0.2K 的官方档位为每百万 3／14 元，同样 8 次约 0.52 元。切换仅在账号可用性或作者选择后进行；不能把不同模型的组间差异归因于 LG。[相同定价表](https://docs.bigmodel.cn/cn/guide/start/pricing)

## 对照与样本

LG 使用当前受控 R5 产品路径；简化提示基线使用同模型、协议、输出参数与等价事实。为限制到 8 次生成，本轮章节设为无分歧、作者已明确方向的单阶段任务（`plot_disagreement=false`），方向写入作者请求；不会伪造已批准的选择记录来跳过分歧流程。不比较自动方案生成与审读成本，它们需要追加请求和独立实验口径。

| 样本 | 固定任务 | 首要评价 |
| --- | --- | --- |
| P1 对话润色 | 约500字，选80字，固定人物与事实 | 选区外保持、声音、流畅度、事实变化 |
| P2 叙述润色 | 另一独立场景的叙述段 | 视角、文风、意象、越界修改 |
| C1 冲突短章 | 已定方向、3条约束，约800字 | 因果、动机、冲突、方向与事实遵守 |
| C2 信息差短章 | 明确人物／读者／作者知道什么，约800字 | 行为合理性、伏笔、提前泄露 |

材料只来自合成样本，不读取正式作品或 Library。两组都记录完整可观察输入、输出与中间制品，不索取模型内部思维链。LG 的包装、Schema 与准备开销单独统计；不把简化基线冒称为完整通用 Coding Agent 对照，也不宣称当前 R5 已具备全书信息隔离。所有输出只作实验候选，不进入正式正文或 Canonical。

## 评价、停止与后续

匿名打乱结果，由作者盲评因果、人物动机、语言声音和任务遵守，各1—5分并写具体依据。选区外差异、固定事实冲突、提前泄露、结构错误另外计数。记录请求数、输入／输出／缓存／推理用量、延迟、失败和费用；作者澄清、选择、改动字数、返修轮次和耗时另记，不能用工程测试数代替文学质量。

没有账号配置、费用批准、可靠计数或实际协议验收时，不启动正文实验。发生秘密泄露、越界写入、用量不明或预算不足时停止，保存结果和故障证据，不自动增加调用或切换模型。

8 次只用于发现明显问题，不足以证明统计优势或长期一致性。若值得继续，再另行确定连续4章、两组各两次运行的16次正文生成预实验，并插入一次旧章修订；其费用与人工审读另批。真正长篇的章数、总字数、修订任务和停止条件另定，不能从本轮5元建议推定授权。
