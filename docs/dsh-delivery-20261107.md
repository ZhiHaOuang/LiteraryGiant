# LiteraryGiant 本机插件版交付

日期：2026-11-07。阶段交付，供体验、梳理与后续精简。

## 打开

```sh
open -a /Applications/LiteraryGiant.app
```

使用这个绝对路径，避免打开 `~/Applications` 中旧的同名 App。当前二进制为此前已编译的 `0.2.2-rc.1.20261104.1`，已使用 LiteraryGiant 名称和指定照片图标。本轮更新的是插件与本机配置，未重打 DMG。

日常 App 共 23 个插件：17 个文学／执行插件、指定的五个基础插件、lg-brand。全部从项目源码目录链接，已逐项在日常桌面确认运行。依赖项目目录保留。

## 从哪里体验

| 入口 | 当前能力 |
|---|---|
| 小说控制台 | 登记或创建作品、概况、章节进度、待审版本、故事索引、监督策略 |
| 文学编辑台 | 正文和候选比较、局部编辑、审阅、反馈改稿、作者采用、章节文件同步、质量报告 |
| 故事规划 | 卷章与场景结构、三个方向、作者选择、场景计划 |
| 文学工作流 | 构思到整章生成、逐场和跨章起草、审阅改稿、旧运行历史快照 |
| 文学任务 | DSH 原生会话提出文学任务后，由作者预览并确认执行 |
| 故事记忆／文学资料 | 正文事实提案、认知与伏笔、资料检索、五类待审分析卡 |
| Plugins → lg-agents | 专家启用状态及补充要求 |
| 作者偏好／修订影响／文学方法 | 写作偏好、直接引用追踪、15 种文学 Skills |
| 作品导出 | 六类内容导出 Markdown、TXT、Word |

首次建议新建一部体验作品，创建一章，再测试保存候选、审阅与采用。采用正文、确认正式事实、批准资料卡分别由作者执行。作品和 Library 数据没有在本次交付中迁移或重写。
